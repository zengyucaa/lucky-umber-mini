# lucky-umber-mini

I love Open Web Standards, stay up-to-date with ECMAScript, and I'm a subscribed member to IETF Working Groups.

处理日常小任务的工具

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 备注

就是给自己省点事，没做太多抽象。

## 安装

```bash
git clone https://github.com/USER/lucky-umber-mini.git
cd lucky-umber-mini
npm install
```
